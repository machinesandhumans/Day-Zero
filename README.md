# Day Zero

An interactive cybersecurity awareness module built around the attack on French supermarket refrigeration systems.

Live site: https://machinesandhumans.github.io/Day-Zero/

Pages: `index.html` (the night it happened), `store.html` (3D), `store-2d.html` (drawn fallback), `defense.html`, `avoid.html`, `you.html`. Plain static HTML, CSS and JS; no build step.

## Call Back: deepfake module

`callback/` is a follow-on module that plays after the Call Back video: how Ryan becomes the Exec, where the source material comes from, how the scam gets access, the red flags, and how to beat it. Pages: `callback/index.html` (the mask), `sources.html`, `play.html`, `tells.html`, `defend.html`. It reuses `style.css` plus `callback/cb.css`. Stills and two short muted clips in `callback/img` and `callback/clips` come from the v24 cut.
